# Comerciatos para computador

Instaladores do app do Comerciatos para Windows 10/11 (64 bits).

**Baixar:** [Comerciatos-Setup.exe](https://github.com/robertlogandua/comerciatos-desktop/releases/latest/download/Comerciatos-Setup.exe) — ou pelo site: https://comerciatos.com.br/baixar/computador

O programa se atualiza sozinho a partir das releases deste repositório.
